# esp32-hub

Main firmware for the ESP32-S3 that acts as the caravan's automation hub:
OpenThread Border Router, BLE central (Power Queen BMS) + peripheral (phone
app), VE.Direct parser, INA219 power monitoring, detection circuits, SIM7600
SMS/GPS, T-Encoder UART link, rules engine.

Framework: **ESP-IDF** (C). See [`../README.md`](../README.md) for the planned
module breakdown under `main/` and the full system architecture.

Not yet implemented — this directory is a placeholder until the ESP-IDF project
is scaffolded.
